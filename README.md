# ReportAI — Landing Page

> Générateur de rapports automatiques avec IA — Landing page de validation + démo interactive

## 🎯 Concept

ReportAI transforme des données brutes (CSV, Excel, Google Sheets) en rapports PDF professionnels avec commentaires IA en 30 secondes.

**Cible** : Contrôleurs de gestion, PME, cabinets comptables, chefs de projet.

## 🚀 Démo live

Ouvrir `index.html` directement dans un navigateur — aucune dépendance, 100% frontend statique.

## 📋 Fonctionnalités de la démo

- ✅ 3 jeux de données d'exemple (Ventes, RH, Projet)
- ✅ Import CSV réel (parsing côté client)
- ✅ Simulation du pipeline d'analyse IA (steps animés)
- ✅ KPI cards auto-générées
- ✅ Tableau de données formaté avec badges de statut
- ✅ Graphique automatique (Chart.js)
- ✅ Commentaire IA contextuel
- ✅ Simulation téléchargement PDF
- ✅ Formulaire liste d'attente

## 🛠 Stack

- HTML/CSS/JS vanilla (zéro framework)
- Tailwind CSS (CDN)
- Chart.js (CDN)
- Google Fonts
